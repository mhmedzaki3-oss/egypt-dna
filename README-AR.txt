- دعم البحث عن موضوعات HORUS بالاسم العربي أو العنوان الإنجليزي، وعرض الإجابة باللغة المختارة.

- Service Worker جديد: egypt-dna-v1.4.1 مع تحديث فوري للنسخة وتنظيف الكاش القديم.

الحدود المعروفة:
- HORUS محرك معرفة محلي داخل التطبيق، وليس نموذج ذكاء اصطناعي متصلًا بالإنترنت.
- الترجمات الإنجليزية صيغ تعليمية للمحتوى العربي، ولا تعني اعتمادًا رسميًا من أي جهة.
- المصادر المعروضة لكل موضوع يجب مراجعتها دوريًا قبل أي استخدام أكاديمي أو نشر مؤسسي.
- لم يتم النشر إلى GitHub Pages أو اختبار التثبيت على جهاز Android فعلي ضمن هذا التسليم.

4) لتحديث نسخة PWA بعد النشر، أغلق التطبيق وأعد فتحه بعد تحميل النسخة الجديدة.
